StageMatch — version beige et bleu

Version HTML/CSS/JavaScript avec accueil, catalogue, catégories, détails d’offres fictives, inscription/connexion Supabase, candidatures étudiants et espace entreprise. Les offres publiées et candidatures réelles utilisent Supabase; les cartes explicitement marquées comme démonstration restent fictives. Le formulaire de contact reste une démonstration locale.

Pour activer la confirmation des e-mails, servez le site par HTTP/HTTPS, configurez Authentication > URL Configuration dans Supabase avec l’URL du site, et suivez SUPABASE.md.
